# SIGE-LS360

Sistema de Registro y Escalamiento de Incidencias Técnicas - La Sirena 360.

Proyecto de la asignatura Programación III (FGI-207), UAPA.

## Problema
Las tiendas de La Sirena 360 no tienen un canal formal para reportar fallas del sistema POS o de inventario al equipo central de TI, ni un historial de incidencias.

## Módulos
1. Registro de Incidencias
2. Clasificación y Prioridad
3. Notificación a TI Central
4. Seguimiento y Resolución
5. Historial y Reportes

## Tecnologías propuestas
HTML, CSS y JavaScript (interfaz), IndexedDB (almacenamiento local), Node.js con Express y base de datos (backend), Git y GitHub (control de versiones).
